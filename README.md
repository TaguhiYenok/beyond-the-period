# Beyond the Period: Mapping Global Menstrual Health Inequality

## Overview

Beyond the Period is an interactive data visualization project designed to raise awareness about period poverty and menstrual health inequality around the world.

Our goal is to combine publicly available data from sources such as UNICEF and the World Bank to create a centralized dataset and an interactive website where users can explore menstrual health access across countries.

## Project Features

- **Menstrual Health Inequality (MHI) Score:** A proposed country-level metric measuring access to menstrual products, sanitation, and private facilities. Higher scores indicate better access.
- **Interactive World Map:** Visualize and explore country-level MHI scores.
- **Country Comparisons:** Compare menstrual health indicators across countries.
- **Additional Visualizations:** Explore charts and graphs highlighting global inequalities.
- **Take Action:** Find educational resources, organizations, and opportunities to support menstrual equity.

## Data Sources

Planned sources include UNICEF and the World Bank. Final datasets, scoring methodology, and limitations will be documented as the project develops.

## Technologies

- Python for data cleaning and score calculations
- HTML, CSS, and JavaScript for the website
- GitHub for version control and collaboration
- Netlify or a similar service for website deployment

In development — UC San Diego CSE 194 / CSE 291A course project.

## Methodology

The MHI score is a proposed project-specific measure, not an official published index. Its methodology, data coverage, and limitations will be documented before scores are released.
